# Themes

A theme changes the main color of Ignite: buttons, links, progress bars and charts. You can keep up to five themes and switch between them whenever you like.

## Create a theme

1. Open **Settings > Appearance** and find the **Themes** section.
2. Choose **New theme**.
3. Give it a name and pick a color.
4. Save. The new theme is used straight away.

Any color works. The text on buttons switches between black and white on its own, so it stays readable on light and dark colors alike. The preview in the form shows the result in light and in dark mode before you save.

## A different color in dark mode

By default a theme uses the same color in light and dark mode. Tick **Use a different color in dark mode** to pick a second one. A brighter color often reads better on a dark background.

## Switch, edit or delete

Each theme in the list has three actions:

- **Use** makes it the theme in use.
- **Edit** changes its name or colors.
- **Delete** removes it. If it was in use, Ignite goes back to its built-in theme.

The first entry in the list, **Ignite**, is the built-in theme. Choose **Use** on it to go back to the original colors. It cannot be edited or deleted.

## What a theme does not change

The Ignite logo keeps its own colors. The welcome page and the sign-in pages always use the built-in colors, and the colors that carry a meaning stay the same: green for completed, amber for paused, red for deleting.
